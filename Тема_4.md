## Лабораторная работа №9

```python
        f"Через {n} дней будет {result.date()}. "
        f"День недели - {result.isoweekday()}"
    )

if __name__ == '__main__':
    main()
```

## Самостоятельная работа №1
### Дайте подробный комментарий для кода, написанного ниже. Комментарий нужен для каждой строчки кода, нужно описать что она делает. Не забудьте, что функции комментируются по-особенному.
![Меню](pic/sam4_1_zadanie.png)

```python
# Импорт модуля datetime для работы с датой и временем
from datetime import datetime
# Импорт функции sqrt из модуля math для вычисления квадратного корня
from math import sqrt

# Определение главной функции, которая принимает произвольное количество именованных аргументов
def main(**kwargs):
    """
    Вычисляет длину вектора по теореме Пифагора
    Параметры:
        **kwargs (словарь) - элементы со значениями начала и конца вектора
    Возвращает:
        float: длина вектора
    """
    #Проходимся по элементам kwargs с ключом key
    for key in kwargs.items():
        # Вычисление длины вектора по теореме Пифагора
        result = sqrt(key[1][0] ** 2 + key[1][1] ** 2)
        # Вывод результата вычисления в консоль
        print(result)


# Проверка, запущен ли скрипт напрямую (а не импортирован как модуль)
if __name__ == '__main__':
    # Запись текущего времени в переменную start_time (время начала выполнения программы)
    start_time = datetime.now()

    # Вызов функции main с передачей пяти именованных аргументов
    # Каждый аргумент - список из двух чисел [x, y]
    main(
        # Векторы с координатами
        one=[10, 3],
        two=[5, 4],
        three=[15, 13],
        four=[93, 53],
        five=[133, 15]
    )

    # Вычисление времени выполнения программы (разница между текущим временем и временем начала)
    time_costs = datetime.now() - start_time

    # Вывод времени выполнения программы
    print(f"Время выполнения программы - {time_costs}")
```
### Результат.
![Меню](pic/sam4_1.png)

## Выводы

Программа вычисляет длину вектора по его координатам, используя теорему Пифагора. Функция main(**kwargs) принимает произвольное число именованных аргументов, где каждый аргумент — это список координат. Для каждого вектора вычисляется и выводится его длина. Дополнительно программа замеряет и выводит время своего выполнения.

### Напишите программу, которая будет заменять игральную кость с 6 гранями. Если значение равно 5 или 6, то в консоль выводится «Вы победили», если значения 3 или 4, то вы рекурсивно должны вызвать эту же функцию, если значение 1 или 2, то в консоль выводится «Вы проиграли». При этом каждый вызов функции необходимо выводить в консоль значение “кубика”. Для выполнения задания необходимо использовать стандартную библиотеку random. Программу нужно написать, используя одну функцию и “точку входа”

```python
import random

def cubic():
    value = random.randint(1, 6)

    print(f"Выпало: {value}")

    if value == 5 or value == 6:
        print("Вы победили")
    elif value == 3 or value == 4:
        print("Бросаем еще раз...")
        cubic()
    elif value == 1 or value == 2:
        print("Вы проиграли")

if __name__ == "__main__":
    cubic()
```
### Результат.
![Меню](pic/sam4_2.png)

## Выводы

Программа имитирует бросок игральной кости с помощью функции random.randint(). В зависимости от выпавшего значения реализована следующая логика: при значениях 5-6 — победа, 3-4 — рекурсивный повтор броска, 1-2 — проигрыш. Рекурсивные вызовы функции наглядно демонстрируют, как программа может "продолжать игру" до достижения конечного результата.
