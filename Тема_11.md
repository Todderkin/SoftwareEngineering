## Лабораторная работа №2
### Класс итератор с гибкой настройкой и удобными применением

```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self

    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__ == "__main__":
    counter = CountDown(5)
    for i in counter:
        print(i)
```

![Меню](pic/lab11_2.png)

## Выводы

В данном коде показан пример итератора с гибкой настройкой и удобным применением. Был создан класс CountDown, который представляет собой итератор. Он принимает число start в качестве аргумента конструктора, которое показывает, с какого числа нужно начинать генерировать числа до 0 включительно.

## Лабораторная работа №5
### Такой же счетчик, как и в первом задании, только это генератор и использует yield

```python
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```
### Результат.
![Меню](pic/lab11_5.png)

## Выводы

В данном коде создана функция countdown(), которая является генератором и возвращает объект-генератор. Происходит вызов этой функции, а затем вывод последовательности чисел от count до 0 включительно.

## Самостоятельная работа №1
### Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

```python
def fib(n):
    a, b = 1, 1
    count = 0
    while count < n:
        yield a
        a, b = b, a + b
        count += 1

if __name__ == '__main__':
    for i, num in enumerate(fib(201)):
        if i == 200:
            print(num)
```
### Результат.
![Меню](pic/sam11_1.png)

## Выводы

В данном коде реализован генератор чисел Фибоначчи, начиная с 1, 1. Функция fib(n) генерирует ровно n чисел Фибоначчи, используя инструкцию yield для создания итератора. Это позволяет экономить ресурсы памяти, так как числа генерируются "на лету" по одному, а не хранятся все сразу в памяти. В основном блоке программы происходит итерация по 201 сгенерированному числу (индексы от 0 до 200), и выводится в консоль число с индексом 200, которое является 201-м по порядку, но соответствует 200-му числу Фибоначчи в последовательности.

## Самостоятельная работа №2
### К коду предыдущей задачи добавьте запоминание каждого числа Фибоначчи в файл “fib.txt”, при этом каждое число должно находиться на отдельной строчке. Результатом выполнения задачи будет листинг кода и скриншот получившегося файла

```python
def fib(n):
    a, b = 1, 1
    count = 0
    while count < n:
        yield a
        a, b = b, a + b
        count += 1


if __name__ == '__main__':
    with open("fib.txt", "w", encoding="utf-8") as file:
        for i, num in enumerate(fib(201)):
            file.write(f"{num}\n")
            if i == 200:
                fibonacci_200 = num

    print(f"200-е число Фибоначчи: {fibonacci_200}")
    print("Все числа записаны в файл 'fib.txt'")
```

## Выводы

В модифицированном коде сохранена функция-генератор fib(n) для эффективного создания чисел Фибоначчи. Добавлена функциональность записи всех сгенерированных чисел в текстовый файл "fib.txt", где каждое число располагается на отдельной строке. При этом программа параллельно определяет 200-е число Фибоначчи и выводит его в консоль. ## Общие выводы по теме
Итераторы и генераторы в Python являются мощными инструментами для эффективной работы с последовательностями данных. Ключевое преимущество генераторов, создаваемых с помощью инструкции yield, заключается в "ленивых" вычислениях - элементы генерируются по мере необходимости, что позволяет работать с бесконечными последовательностями или очень большими наборами данных без перегрузки оперативной памяти. Это особенно ценно при обработке больших объемов информации или математических последовательностей, подобных числам Фибоначчи, где хранение всех элементов в памяти может быть нецелесообразным или невозможным.
